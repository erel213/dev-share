# dev-share / marketing

This project contains marketing assets for dev-share: videos, images, copy, and related creative work.

## Purpose

Produce marketing collateral that communicates what dev-share does and drives user acquisition.

## Structure (expected)

```
marketing/
  videos/       — screen recordings, demos, social clips
  images/       — screenshots, banners, social cards, logos
  copy/         — taglines, ad copy, landing page text
  assets/       — raw source files (Figma exports, fonts, etc.)
```

## Context

dev-share is a developer tool. See the main repo for product context:
- Backend: Go/Fiber, JWT auth via httpOnly cookies
- Frontend: React 19 + TypeScript, Vite, Tailwind CSS, shadcn/ui
